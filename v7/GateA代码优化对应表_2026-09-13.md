# Gate A v5 最小命名与代码对应表

> 结果边界：本文件只报告协议和代码修改；尚未运行新的正式仿真，表中成功率保持 `TBD`。

## 唯一主问题

Gate A 只检验：在相同任务可操作候选集 $\mathcal P_e$ 上，真实 rollout 经验 oracle 是否显著优于预注册的最强 policy-agnostic 几何选点器。

| 对象 | v5 严格定义 | 代码结果 |
| --- | --- | --- |
| $\mathcal P_e$ | 统一通过底盘碰撞、像素可见性和任务关键轨迹可达性过滤的 48 个候选 | 保留 32+16 两轮候选生成；旧固定环带已删除 |
| $p_{\mathrm{geom}}$ | $\arg\max_{p\in\mathcal P_e}G_e(p)$ | `GEOMETRY_SCORE_FIELDS` 只包含轨迹 IK 残差、关节裕量、接近方向、manipulability 和像素可见性；不读取 rollout 结果 |
| $p_{\mathrm{oracle}}$ | $\arg\max_{p\in\mathcal P_e}\hat S_{\mathrm{search}}(e,p)$ | 原 `p_star` 统一重命名；并列时使用预注册、selector-blind 随机破平局 |
| $H_{\mathrm{geom}}$ | $\hat S_{\mathrm{val}}(p_{\mathrm{oracle}})-\hat S_{\mathrm{val}}(p_{\mathrm{geom}})$ | Gate A 唯一主指标；搜索和验证种子严格分离 |

## 原位姿名称的处理

| 原名称 | v5 处理 | 实现结果 |
| --- | --- | --- |
| `p_default` | 从 Gate A selector 和 baseline 删除 | 只保存 `simulator_default_x/y/theta` 元数据；若显式启用 debug 代理，才可作为训练位姿近似 |
| `P_train` | 只作候选生成先验 | 在任务法向/切向上作 2.5–30 cm 多尺度扰动，不作 baseline |
| `p_demo` / `p_ref` | 统一为 `p_train` | 只进入 sanity-check SR，不进入 $H_{\mathrm{geom}}$ |
| `p_nav` | 从 Gate A 删除 | pose registry 和运行脚本不再需要 navigation CSV；导航基线后移到端到端实验 |
| `p_near` | 改为 `nearest_only` | 只作几何消融/上包络稳健性检查 |
| `p_IK` | 改为 `ik_only` | 只作几何消融/上包络稳健性检查 |
| `p_vis` | 改为 `visibility_only` | 只作几何消融/上包络稳健性检查 |
| 新增几何消融 | `manipulability_only` | 使用任务轨迹上的最小 Jacobian manipulability |
| `p_geom` | 保留 | Gate A 唯一部署型主 baseline |
| `p*_GT` / `p_star` | 统一为 `p_oracle` | 只使用搜索 rollout 选点，再用新种子验证 |
| Mobi-π / N2M / SkillBasin | Gate A 不定义 | 后移到 Gate B/C 或主论文完整 baseline 实验 |

## 几何稳健性检查

$S_{\mathrm{geom}}^+$ 事后取 `p_geom` 和四个单几何消融中验证成功率最高者，并输出 $H_{\mathrm{geom}}^+=S(p_{\mathrm{oracle}})-S_{\mathrm{geom}}^+$。它是更保守的稳健性分析，不替代唯一主指标 $H_{\mathrm{geom}}$。
